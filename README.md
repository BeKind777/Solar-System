# Solar System Orrery / 太阳系仪

A rotatable 3D solar system model: planetary positions and angles, moons, dwarf planets,
telescope visibility, Lagrange points, and rocket transfer calculations. English / 中文.

可旋转的太阳系三维模型：行星位置与角度、卫星、矮行星、望远镜可观测天体、拉格朗日点和火箭转移计算，支持中英文切换。

**Live demo / 在线运行:** https://bekind777.github.io/<仓库名>/
