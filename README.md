# Solar System Orrery

A rotatable 3D solar system model: planetary positions and angles, moons, dwarf planets,
telescope visibility, Lagrange points, and rocket transfer calculations. English / 中文.

## Credits 

- Planet and Moon textures: the [threex.planets](https://github.com/jeromeetienne/threex.planets)
  project (MIT license), which is based on Solar System Scope textures and NASA imagery.
- Planet positions use JPL approximate Keplerian elements.
